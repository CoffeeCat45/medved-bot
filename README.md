# Медведь онлайн

Информационный чат-бот для первичной маршрутизации пациента на основе симптомов и анамнеза. Работает как Mini App внутри мессенджера MAX.

> Бот не ставит диагноз, не назначает лекарства и не заменяет экстренную медицинскую помощь.

## Цель проекта

Собрать жалобы и анамнез пациента, выявить критические состояния (Red Flags) и сформировать итоговую карточку маршрутизации:

- к какому врачу обратиться (терапевт, кардиолог, педиатр, ЛОР и др.);
- с какой срочностью (экстренно / в течение 24 часов / планово / самопомощь);
- куда обращаться (скорая помощь, приёмный покой, поликлиника, телемедицина, аптека).

## Архитектура

Обработка симптомов выполняется тремя последовательными слоями; порядок слоёв критичен.

```
[Текст жалобы пользователя]
        |
  +-------------+
  | Слой 1:     |  Детерминированные правила в YAML.
  | Red Flags   |  Выполняется ДО обращения к LLM:
  | (safety.py) |  нейросеть не может пропустить
  +-------------+  инфаркт или инсульт.
        |
        | (если критический признак не найден)
        v
  +-------------+
  | Слой 2:     |  Резервный слой на случай недоступности
  | NLP matcher |  LLM: keyword-matching и определение
  | (nlp.py)    |  локализации.
  +-------------+
        |
        v
  +-------------+
  | Слой 3:     |  Классификация свободного текста в одну
  | GigaChat    |  из 13 категорий (боль, температура,
  | (llm_client)|  дыхание, ЖКТ, кожа, неврология, травма,
  +-------------+  ЛОР, глаза, психиатрия, сердце, простуда,
        |         другое).
        v
  +-------------+
  | Router      |  Категории и модификаторы: ребёнок,
  | (router.py) |  беременность, хронические заболевания,
  +-------------+  тип оплаты.
```

Ключевой принцип: LLM имеет право только классифицировать жалобу. Модель не формирует срочность и не может её понизить — срочность определяется детерминированными правилами и может только повышаться.

## Безопасность

- **ФЗ-152.** Серверная база данных не используется. СНИЛС и номер полиса ОМС не передаются во frontend: поля обрезаются на backend в эндпоинте `/api/auth/me`. История обращений хранится исключительно в `localStorage` устройства пользователя.
- **Защита от prompt injection.** Модель не получает и не возвращает поля `urgency` и `is_emergency`, поэтому не может изменить их через содержимое пользовательского текста.
- **CORS.** Явный список разрешённых origin, `allow_credentials=False` (авторизация через Bearer-токен, не через cookie).
- **Отказоустойчивость.** Таймауты 10 секунд на обращения к LLM и CORE-сервису с автоматическим переключением на резервный NLP-слой.

## Тестирование

```bash
cd backend
python -m pytest -v
```

Набор из 89 тестов покрывает:

- 13 обязательных Red Flags из технического задания и дополнительные формулировки каждого;
- нормализацию «ё/е» и числовые пороги температуры (включая запись через запятую);
- логику маршрутизации: модификаторы, локализация, хронические заболевания, тип оплаты;
- интеграционные тесты всех API-эндпоинтов;
- граничные случаи: XSS, SQL-инъекции, длинные тексты, пустой ввод.
